## Implemented

- New pack flow offers narrated video for YouTube/TikTok and recommended/video/carousel/single-image choices for Instagram. It saves the pack plus durable preparation intent, then opens PackView for a context recommendation and explicit paid Generate. Selected media targets skip paid still-image generation. Preparation and explicit carousel override survive refresh.
- PackView extends existing controls with recommendation/reason, format override, source details, queued/preparing/narrating/rendering/ready/failed/uncertain/cancelled guidance, explicit cancellation/retry and paid-retry acknowledgment. Workspace polling follows durable progress after refresh. Previous attachment stays visible until successful replacement. Disabled cohorts do not receive new-generation offers; Viewer controls are read-only.
- Real video controls and video/slides downloads use tenant media routes. Carousels show all slides, order/count, thumbnails, previous/next and arrow-key navigation. Authenticated script/source/storyboard/caption/alignment downloads use the backend's Viewer-readable `social.mediaNotes` action, not an invented URL route.
- Server target resolution/preflight/send-time media checks carry every ordered slide; actual JPEG format/bytes, decoding, ownership and Instagram proportions are checked. Active replacement blocks publication and schedule-all. Generated video/slides set AI-media metadata. Uploaded video or regenerated still clears competing attachments/generated references and increments media revision; pending/posted media cannot be overwritten. TikTok consent remains reset on source media/caption changes.
- Default-off automatic explainer preference is saved in existing settings. Daily generation uses identical durable intent with fresh date/activation options. Completion resumes only a still-authorized active, paid, same-day program; standalone schedules only missing posts on currently selected platforms. Autopilot waits while media is pending and hands off failures/uncertainty. No master Autopilot switch or platform consent is silently changed.
- New-media `social.generate` jobs use active request singleton and stable tenant/request pack IDs, so a worker failure after pack/intent commit reuses the existing pack on retry.
- Privacy disclosure describes selected source/script processing by configured AI/ElevenLabs and publicly retrievable publishable media, while retaining the existing connected-YouTube-data AI boundary. Existing terms already cover AI content; no extra terms edit was required.
