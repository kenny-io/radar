# Reminder copy review

PM review against the owner's launch script, actual actions and latest correction. This is not an independent QA claim.

Each message identifies existing useful work and offers a concrete next action. Brief copy invites a meaningful contribution rather than claiming a sale or discovery win. Calendar copy asks users to select topics, then review/schedule their drafts; it does not equate topic approval with publication. Article copy offers reuse, and social-pack copy points to review/post/schedule. Single-section subjects name the task. A combined email has one primary button, with ordinary links for other sections.

No guilt, countdowns, inactivity labels, exaggerated urgency, invented personalization or35%outcome claim. The stored account/business/source state supplies names, titles and counts. The first-attempt body is refreshed so an action completed during the waiting period removes its section; provider retries preserve the exact accepted-attempt body/key. No click/open tracking pixels.

The existing actual logo and compact button are retained. Optional work reminders add a clear work-specific unsubscribe and compact sender/address information. Existing core messages keep their shorter footer. Full local preview gallery contains the nine core emails plus one combined work template and four single-condition examples.
