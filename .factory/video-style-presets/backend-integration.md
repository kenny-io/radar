## Five renderers and layout

Drawn keeps accepted baseline pixels. Kinetic uses Sans, larger words without full cards, reserved semantic kind icons, state chips/underlines and a cue-driven active-label strip below captions. Editorial uses warm print composition, left-aligned Sans blocks/decks, scene-order folios, panels/keylines and calm introductions. Paper cut uses filled silhouettes, offset solid shadows, tape accents, small deterministic tiled grain and a bounded whole-group settle. Blueprint uses engineering grid/title frame, ports, crisp Sans, wire traces, scan reveal and bracket emphasis. No new claims, dimensions, stock material or generated executable content.

APIs retain backward-compatible defaults:

- `layoutScene(scene,carousel,videoStyle='drawn')`; cache key is mode+style (at most10 entries/scene).
- `videoFrame(timeline,seconds,canvas?,videoStyle='drawn')`.
- `carouselFrame(scene,index,total,videoStyle='drawn')`.
- `renderMedia(...,progress,renderStyle?)`; isolated child validates trusted ID/version and receives no provider/database credentials.

Every fitted TextBlock carries actual registered family and alignment; Sans measurements are not borrowed from Kalam. Existing title/node/state/edge/summary/units minima and full-word glyph/collision checks remain. Motion/shadows stay in protected geometry; no per-frame layout/random jitter. Captions retain exact Kalam48 wrapping/text/timestamps/y1410..1630; only panel/text palette changes. Focus/footer/header reserves are explicit. Contrast tests verify at least4.5 for actual diagram/caption text/material pairs. Global renderer concurrency/time/memory/bytes/dimensions/fps remain unchanged. Worker still needs bundled Kalam/Noto and its existing fontconfig/Noto CJK fallback, FFmpeg/ffprobe, native canvas and authenticated bounded storage access; no added dependency.
